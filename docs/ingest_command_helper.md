# Ingest JSON Links

Raw GitHub links to every dataset's ingest JSON file(s) on `master`, for use
with tooling that ingests directly from a URL. One row per ingest JSON;
datasets with multiple outputs have multiple rows.

`geoboundaries` and `tiger` generate their ingest JSON dynamically at
runtime rather than committing a static file, so they have no row here.
`_archive/` datasets and any `_new`-suffixed duplicate directories are
excluded.
